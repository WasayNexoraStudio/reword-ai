When to use Formal mode

Use it when a draft is true but too spoken: “gonna”, “a bunch of”, or “I think maybe”. Formal mode aims for complete sentences and a workplace or classroom register. It is not a grammar exam and it will not add citations.

Read formal vs fluent writing if you are choosing between Formal and Fluency.
